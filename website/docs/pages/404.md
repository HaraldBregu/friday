# 404 Page

Route: `/404.html`

Source: `src/pages/404.astro`

## Purpose

The 404 page is the static not-found route. It tells users that the requested route is unavailable and sends them back to the home page.

## Content Sources

- Copy is defined directly in `src/pages/404.astro`.
- The page uses `src/components/Icon.astro` and `src/layouts/Layout.astro`.
- Layout metadata sets `noindex` so the page is not indexed.

## Feature Docs Used

- None directly. This page is infrastructure and navigation support.

## Notes

Keep this page short and stable. It should avoid product claims because users may land here from stale or mistyped URLs.
