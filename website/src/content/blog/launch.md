Kucedr starts from a narrow idea: an assistant should be useful because it can
coordinate work, not because it has a large chat box.

The first preview focuses on a desktop command surface, provider routing, and
channel updates. The goal is to make every action visible enough that a team can
trust it, change it, and improve it over time.

## What is included

- A static marketing site that is easy to customize.
- A data-driven integrations page.
- Blog content powered by Astro content collections.
- Dark-first styling with a light theme toggle.

## What comes next

The next milestone is deeper contribution guidance: adapter templates, workflow
examples, and stronger documentation for approval boundaries.
