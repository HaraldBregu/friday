# Releasing Kucedr

The canonical release instructions are now part of
[Development, Testing, and Deployment](DEVELOPMENT.md#deployment).

The guide covers:

- local development for the Electron app, SDK, CLI, and example project;
- unit, integration, end-to-end, coverage, package, and CI checks;
- normal branch pushes;
- one-time npm trusted-publisher and desktop-signing setup;
- tag-based Electron, SDK, and CLI deployments;
- deployment verification, recovery, and troubleshooting.
